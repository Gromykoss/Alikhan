# Alikhan — PROJECT.md

## Что это

WhatsApp AI-агент для строительной группы золоторудного месторождения Джеруй. Бот находится в рабочей WhatsApp-группе, запоминает всё происходящее (фото, документы, обсуждения) и автоматически формирует строительную отчётность по ГОСТ.

## Зачем / как возникла идея

Стройка на высоте 2700м. Прорабы и ИТР ежедневно заполняют бумажные журналы, фотографируют объекты, отчитываются. Сергей управляет проектом удалённо. Нужен был инструмент, который:
1. Собирает всё из WhatsApp (фото, сообщения, документы) — потому что это единственный канал связи на объекте
2. Превращает сырые данные в ГОСТ-отчёты (ЕЖО, АВР, Снимок дня)
3. Хранит всё в структурированной БД (ОЖР) для будущего аудита

## Возможности

- ЕЖО (Ежедневный Журнал Отчёта) — автоматическая генерация из фото и сообщений
- АВР (Акты выполненных работ): КС-2 (14 колонок, акт за период), КС-6 (накопительный журнал)
- ВОР (Ведомость объёмов работ) — 837 кодов с расценками ФЕР-2020
- Снимок дня — композит из фото, погоды, выполненных работ
- Погода — автоматический сбор через Open-Meteo
- Опросы (Poll) — бот запрашивает у прорабов данные, парсит ответы, пишет в БД
- QA-парсер — извлекает structured данные из сообщений
- Календарь/напоминания
- STT (Speech-to-Text) — faster-whisper + Grok коррекция для голосовых сообщений
- Vision — Grok анализирует фото и пишет описание состояния конструкций
- Excel-отчёты — заполнение шаблонов .xlsx, diff-формат для ручных правок

## Техстек

- **Язык:** Python (v5)
- **WhatsApp:** Hermes Bridge (:3000) — замена Evolution API (миграция 15.07.2026)
- **БД:** PostgreSQL, 15 таблиц ОЖР по ГОСТ РД-11-05-2007
- **LLM:** Grok (grok-4-latest) для vision и анализа, DeepSeek v4 Pro для оркестрации
- **Отчёты:** Excel (.xlsx) через fill_ejo.py + шаблоны
- **Инфра:** systemd (alikhan.service + alikhan-document-extractor.service)
- **STT:** faster-whisper (локально)
- **Модель:** DeepSeek v4 Pro (оркестратор)

## Текущая стадия

Активен. ЕЖО v10 — финальная, проверена руководителем. Бот работает на коммитах 7a9cca7, 2c3e8ea, 4ab378b. Полный аудит проведён 25.07.2026: 49 багов найдено, 2 CRITICAL + 7 HIGH исправлены. 21 MEDIUM + 19 LOW — не верифицированы.

## Ключевые решения и компромиссы

- **WhatsApp, а не свой интерфейс** — прорабы не будут ставить отдельное приложение. WA уже есть у всех
- **Hermes Bridge вместо Evolution API** — Evolution был нестабилен, Bridge с retry+backoff работает стабильно
- **15 таблиц ОЖР по ГОСТ** — избыточно для стройки, но необходимо для будущих проверок и аудита
- **DeepSeek v4 Pro как оркестратор** — код только через делегирование в Codex/Grok Build
- **Без авто-постинга в прод** — production группа только с явного approval
