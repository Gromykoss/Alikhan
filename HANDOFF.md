## 4. РАССИНХРОН КАНОНА (главная работа впереди)

Проблема, которую вскрыл Сергей: документы проекта **противоречат друг другу** по одному шву — «кто читает какую группу, кто пишет сырьё, кто отвечает».

### 4.1. Что говорит КОД (факт, `bot/whatsapp_commands.py`)

- **Диспетчер читает ТОЛЬКО боевую.** Стр. 199: `for gid, gname in ((PRODUCTION, "PRODUCTION"),):` → `GET /messages?only=<боевая>`.
- **Ответы в песочницу — только gateway**, не диспетчер. Стр. 534–537 комментарий: «Боевая: ТОЛЬКО сбор, ответов НИКОГДА. Песочницу целиком обслуживает Hermes-шлюз».
- **Сырьё пишется только из боевой.** `_save_prod_text` (1199), `_save_prod_photo` (741), `_save_prod_document` (1149) — все с пометкой «из боевой».

- Guard стр. 1248 `if chat_id not in (PRODUCTION, SANDBOX)` — не спасёт: песочница до диспетчера не доходит из-за `only=PRODUCTION`.
